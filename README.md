# TotalC0de

SEO-структура, кластеры запросов и план работы с Яндекс Вебмастером описаны в [SEO-ANALYSIS.md](SEO-ANALYSIS.md).

Статический сайт для `total-code.ru`, рассчитанный на публикацию через GitHub Pages.

## Что уже настроено

- главная страница, светлая бело-синяя тема и адаптивная навигация;
- прежняя страница социальных ссылок по адресу `/links/`;
- ссылки на два профиля Avito, Telegram, VK и личные сообщения;
- отдельные страницы об условиях продажи, оплате и возврате, персональных данных и согласии;
- отложенная Яндекс Метрика: код загружается только после согласия посетителя;
- файл подтверждения Яндекс Вебмастера, `robots.txt`, `sitemap.xml`, canonical, Open Graph и Schema.org;
- страница 404 и web manifest.

## Подключение Яндекс Метрики

1. Создать или открыть счётчик для `https://total-code.ru/`.
2. Скопировать только числовой номер счётчика.
3. Вставить его в `assets/config.js`:

```js
window.TOTAL_CODE_CONFIG = {
  yandexMetrikaId: "12345678"
};
```

Метрика запускается после согласия пользователя. Вебвизор намеренно отключён. Цель `external_click` фиксирует переходы по внешним ссылкам.

## Яндекс Вебмастер

1. Добавить сайт `https://total-code.ru/` в Вебмастер.
2. Подтвердить права HTML-файлом `yandex_199e6503523991b8.html` — актуальный файл уже находится в корне. Прежний файл подтверждения сохранён и не мешает проверке.
3. В разделе «Индексирование → Файлы Sitemap» добавить `https://total-code.ru/sitemap.xml`.
4. После публикации проверить в диагностике Вебмастера ответы `200`, canonical и мобильную пригодность страниц.
5. При изменении адресов страниц обновить `sitemap.xml` и canonical в соответствующем HTML.

## Данные, которые нельзя заполнять догадками

Перед публичным запуском необходимо получить и добавить:

- прямые ссылки на отдельные объявления и исходные фотографии товаров, если их нужно показывать вместо оформленных карточек;
- тексты отзывов, имена/инициалы, даты и прямые ссылки на источник либо письменное разрешение на публикацию;
- номер Яндекс Метрики;
- адрес для претензий и возврата, а также рабочий email владельца сайта;
- точные условия передачи каждого вида товара или цифровой услуги, гарантийный срок и правила возврата;
- подтверждение, что все товары допустимы для продажи плательщиком НПД и не являются перепродажей чужих товаров.

## Публикация

Репозиторий уже содержит `CNAME` для `total-code.ru`. После проверки изменений их можно закоммитить и отправить в ветку, из которой настроен GitHub Pages.

Юридические тексты являются техническим шаблоном под текущую модель сайта без корзины и онлайн-оплаты. Перед началом дистанционных продаж их следует проверить с юристом с учётом фактических товаров, способа расчёта и адреса продавца.
